## 🔨 Featured Projects

### ⭐ Recent Work

- **[SmartEnoughCity](https://github.com/rakeshlakshmanan/SmartEnoughCity)** – Cloud-native urban transport intelligence platform: a 4-service microservices system ingesting real-time data from 15+ Dublin transport APIs (GTFS, GTFS-RT, GBFS, Irish Rail, Luas) into PostgreSQL/PostGIS, serving ML-driven mobility indicators through a React dashboard. Deployed on GKE with Terraform, Helm, and Istio. *(Java, Spring Boot, Python, FastAPI, scikit-learn, React, Kubernetes)*
- **[Distributed Traffic Booking System](https://github.com/rakeshlakshmanan/distributed-road-booking)** – A 6-service microservices platform for cross-region journey bookings across three geographic data partitions (Ireland, UK, France), coordinated by a Saga orchestrator with Redis distributed locks and a self-healing reconciler. *(Python, FastAPI, PostgreSQL, Redis, RabbitMQ, AWS)*
- **[DevVault](https://github.com/rakeshlakshmanan/DevVault)** ([Live](https://devvault.qd.je)) – Full-stack AI-powered developer bookmark manager with auto-tagging and summarization via Google Gemini 2.5 Flash, built on an event-driven pipeline and deployed end-to-end on GKE. *(Java, Spring Boot, PostgreSQL, React, Kubernetes)*
- **[EliteCode](https://github.com/rakeshlakshmanan/AdaptiveEliteCode)** – Adaptive coding interview prep platform driven by a Bayesian Knowledge Tracing engine that recommends problems in each user's Zone of Proximal Development, with self-hosted Judge0 sandboxed execution across 6 languages. *(Python, FastAPI, Supabase, scikit-learn, React)*

### 🧠 AI & Intelligent Systems

- **Fall Detection Mobile Application** – Cross-platform Flutter app using sensor fusion (accelerometer, gyroscope, GPS) with cloud-based emergency alerts and real-time location tracking.

### 🌐 Web, Backend & Real-Time Systems
